## 🔄 الـ Flow الكامل لتسجيل الدخول

### المرحلة 1: فتح التطبيق

```
1. التطبيق يفتح
   ↓
2. main() function يشتغل
   ↓
3. يتم تهيئة AuthCubit
   ↓
4. AuthCubit.checkAuthStatus() يشتغل تلقائياً
   ↓
5. يفحص: هل في session محفوظة؟
   
   ✅ نعم → يذهب للصفحة الرئيسية مباشرة
   ❌ لا → يذهب لصفحة Login
```

**الكود:**
```dart
// في main.dart
class _CoditAppState extends State<CoditApp> {
  @override
  void initState() {
    super.initState();
    final authCubit = getIt<AuthCubit>();
    // ... تهيئة الـ router
  }
}

// في AuthCubit
AuthCubit(this._repository, this._tokenManager)
    : super(AuthInitial()) {
  checkAuthStatus();  // ← يشتغل تلقائياً
}

Future<void> checkAuthStatus() async {
  emit(AuthChecking());  // ← يعرض loading

  final tokens = await _repository.getStoredTokens();
  final user = await _repository.getStoredUser();

  if (tokens != null && user != null && tokens.isValid) {
    emit(AuthAuthenticated(user: user, tokens: tokens));
  } else {
    emit(AuthUnauthenticated());
  }
}
```

### المرحلة 2: صفحة Login

```
1. المستخدم يفتح صفحة Login
   ↓
2. LoginScreen._loadSavedCredentials() يشتغل
   ↓
3. يفحص SharedPreferences:
   - هل في username محفوظ؟
   - هل Remember Me مفعّل؟
   ↓
4. إذا نعم: يملأ الـ username تلقائياً
   ↓
5. المستخدم يدخل البيانات:
   - Username
   - Phone Number
   - Password
   ↓
6. المستخدم يضغط "Login"
```

**الكود:**
```dart
class _LoginScreenState extends State<LoginScreen> {
  @override
  void initState() {
    super.initState();
    _loadSavedCredentials();  // ← يشتغل أول ما يفتح
    _initializeDeviceInfo();  // ← يجيب معلومات الجهاز
  }

  /// تحميل البيانات المحفوظة
  Future<void> _loadSavedCredentials() async {
    final prefs = await SharedPreferences.getInstance();
    final savedUsername = prefs.getString('saved_username');
    final rememberMe = prefs.getBool('remember_me') ?? false;

    if (mounted && savedUsername != null && rememberMe) {
      setState(() {
        _usernameController.text = savedUsername;  // ← يملأ تلقائياً
        _rememberMe = true;
        _isLoading = false;
      });
    } else {
      setState(() {
        _isLoading = false;
      });
    }
  }
}
```

### المرحلة 3: Validation (التحقق من البيانات)

```
1. المستخدم يضغط "Login"
   ↓
2. _handleLogin() يشتغل
   ↓
3. _formKey.currentState!.validate() يشتغل
   ↓
4. كل حقل يتم التحقق منه:

   Username Validation:
   ✅ مش فاضي
   ✅ على الأقل 3 أحرف
   ✅ حد أقصى 50 حرف
   ✅ حروف وأرقام و . و _ فقط

   Phone Validation:
   ✅ مش فاضي
   ✅ على الأقل 10 أرقام
   ✅ حد أقصى 15 رقم
   ✅ أرقام صحيحة

   Password Validation:
   ✅ مش فاضي
   ✅ على الأقل 6 أحرف
   ✅ حد أقصى 50 حرف
   ✅ فيه حرف واحد على الأقل
   ✅ فيه رقم واحد على الأقل
   ↓
5. إذا كل شيء صح:
   → يستمر
   
   إذا في خطأ:
   → يعرض رسالة خطأ تحت الحقل
```

**الكود:**
```dart
// Username Validation
String? _validateUsername(String? value) {
  if (value == null || value.isEmpty) {
    return 'اسم المستخدم مطلوب';
  }
  
  if (value.length < 3) {
    return 'اسم المستخدم قصير جداً (على الأقل 3 أحرف)';
  }
  
  if (value.length > 50) {
    return 'اسم المستخدم طويل جداً (حد أقصى 50 حرف)';
  }
  
  if (!RegExp(r'^[a-zA-Z0-9._]+$').hasMatch(value)) {
    return 'اسم المستخدم يحتوي على أحرف غير صالحة';
  }
  
  return null;
}

// Phone Validation
String? _validatePhone(String? value) {
  if (value == null || value.isEmpty) {
    return 'رقم الهاتف مطلوب';
  }
  
  final cleanPhone = value.replaceAll(RegExp(r'[^\d+]'), '');
  
  if (cleanPhone.length < 10) {
    return 'رقم الهاتف قصير جداً (على الأقل 10 أرقام)';
  }
  
  if (cleanPhone.length > 15) {
    return 'رقم الهاتف طويل جداً (حد أقصى 15 رقم)';
  }
  
  if (!RegExp(r'^\+?\d{10,15}$').hasMatch(cleanPhone)) {
    return 'رقم الهاتف غير صحيح';
  }
  
  return null;
}

// Password Validation
String? _validatePassword(String? value) {
  if (value == null || value.isEmpty) {
    return 'كلمة المرور مطلوبة';
  }
  
  if (value.length < 6) {
    return 'كلمة المرور قصيرة جداً (على الأقل 6 أحرف)';
  }
  
  if (value.length > 50) {
    return 'كلمة المرور طويلة جداً (حد أقصى 50 حرف)';
  }
  
  if (!RegExp(r'[a-zA-Z]').hasMatch(value)) {
    return 'يجب أن تحتوي على حرف واحد على الأقل';
  }
  
  if (!RegExp(r'\d').hasMatch(value)) {
    return 'يجب أن تحتوي على رقم واحد على الأقل';
  }
  
  return null;
}
```

### المرحلة 4: حفظ البيانات و Device Info

```
1. Validation نجح
   ↓
2. _saveCredentials() يشتغل
   ↓
3. إذا Remember Me مفعّل:
   → يحفظ Username في SharedPreferences
   
   إذا مش مفعّل:
   → يمسح أي بيانات محفوظة
   ↓
4. تنظيف رقم الهاتف:
   cleanPhone = phone.replaceAll(غير الأرقام, '')
   ↓
5. جمع Device Info:
   - Device ID (معرف الجهاز الفريد)
   - Device Name (اسم الجهاز)
   ↓
6. إرسال الطلب لـ AuthCubit
```

**الكود:**
```dart
void _handleLogin() async {
  if (_formKey.currentState!.validate()) {
    try {
      // 1. حفظ البيانات
      await _saveCredentials();
      
      // 2. تنظيف رقم الهاتف
      final cleanPhone = _phoneController.text
          .replaceAll(RegExp(r'[^\d+]'), '');
      
      // 3. إرسال الطلب
      if (mounted) {
        context.read<AuthCubit>().login(
          username: _usernameController.text.trim(),
          phone: cleanPhone,
          password: _passwordController.text,
          deviceId: _deviceId,     // ← من _initializeDeviceInfo()
          deviceName: _deviceName, // ← من _initializeDeviceInfo()
        );
      }
    } catch (e) {
      ExceptionHandler.logException(e);
      if (mounted) {
        ExceptionHandler.showErrorSnackBar(context, e);
      }
    }
  }
}

/// حفظ البيانات
Future<void> _saveCredentials() async {
  final prefs = await SharedPreferences.getInstance();
  if (_rememberMe) {
    await prefs.setString('saved_username', 
        _usernameController.text.trim());
    await prefs.setBool('remember_me', true);
  } else {
    await prefs.remove('saved_username');
    await prefs.setBool('remember_me', false);
  }
}
```

```dart
Future<Map<String, dynamic>> login({
  required String username,
  required String password,
  required String deviceId,
}) async {
  await _client.post(
    '/auth/login',
    body: {
      'username': username,
      'password': password,
      'device_id': deviceId
    },
  );

      'refresh_token': refreshToken,
      'expires_in': 3600,
```

### المرحلة 7: معالجة النتيجة في AuthCubit

```
1. AuthCubit يستقبل النتيجة من MockAuthApi
   ↓
2. result.fold() يفحص النتيجة:
   
   ❌ فشل (failure):
      → emit(AuthError(message: failure.message))
      → يعرض SnackBar خطأ في UI
   
   ✅ نجح (response):
      → يفحص: هل يحتاج OTP؟
      → يفحص: هل يحتاج Device Verification؟
      → إذا لا: يتم تسجيل الدخول مباشرة
   ↓
3. في حالة النجاح المباشر:
   
   _handleSuccessfulAuth(tokens, user)
   ↓
4. _handleSuccessfulAuth يعمل:
   
   أ) يحفظ الـ Tokens في TokenManager
   ب) يحفظ الـ User في TokenManager
   ج) emit(AuthAuthenticated(user: user, tokens: tokens))
   ↓
5. emit(AuthAuthenticated) يخلي:
   
   → GoRouter يكتشف التغيير
   → redirect في AppRouter يشتغل
   → ينقل المستخدم لـ /home
```

**الكود:**
```dart
// في AuthCubit
result.fold(
  // ❌ في حالة الفشل
  (failure) => emit(AuthError(message: failure.message)),
  
  // ✅ في حالة النجاح
  (response) {
    if (response.requiresOtp) {
      // يحتاج OTP
      emit(AuthOtpRequired(
        sessionId: response.sessionId!,
        phone: phone,
      ));
    } else if (response.requiresDeviceVerification) {
      // يحتاج Device Verification
      emit(AuthDeviceVerificationRequired(
        deviceVerificationId: 
            response.deviceVerificationId ?? 'unknown',
      ));
    } else {
      // ✅ نجح مباشرة
      _handleSuccessfulAuth(response.tokens!, response.user!);
    }
  },
);

// معالجة النجاح
void _handleSuccessfulAuth(AuthTokens tokens, User user) {
  // 1. حفظ الـ Tokens
  _tokenManager.saveTokens(tokens);
  
  // 2. حفظ الـ User
  _tokenManager.saveUser(user);
  
  // 3. تحديث الحالة
  emit(AuthAuthenticated(user: user, tokens: tokens));
}
```

### المرحلة 8: GoRouter Redirect (التنقل)

```
1. emit(AuthAuthenticated) حصل
   ↓
2. GoRouter يكتشف التغيير في AuthState
   ↓
3. redirect في buildRouter() يشتغل:
   
   redirect: (context, state) {
     final authState = authCubit.state;
     final loc = state.matchedLocation;
     
     // فحص الحالة
     if (authState is AuthAuthenticated && isAuthRoute) {
       return '/home';  // ← ينقل للصفحة الرئيسية
     }
     
     return null;  // يبقى في نفس المكان
   }
   ↓
4. المستخدم ينتقل لـ /home
   ↓
5. HomePage تفتح وتعرض:
   - اسم المستخدم
   - الصلاحيات المتاحة
   - الأيقونات حسب الصلاحيات
```

**الكود:**
```dart
// في AppRouter
GoRouter buildRouter(AuthCubit authCubit) {
  return GoRouter(
    initialLocation: '/login',
    refreshListenable: _AuthRefresh(authCubit),
    
    redirect: (context, state) {
      final authState = authCubit.state;
      final loc = state.matchedLocation;

      final isAuthRoute =
          loc.startsWith('/login') ||
          loc.startsWith('/otp') ||
          loc.startsWith('/device');

      // إذا authenticated وفي auth route
      if (authState is AuthAuthenticated && isAuthRoute) {
        return '/home';  // ← ينقل للرئيسية
      }

      // إذا مش authenticated ومش في auth route
      if (authState is! AuthAuthenticated && !isAuthRoute) {
        return '/login';  // ← يرجع للـ login
      }

      return null;  // يبقى في نفس المكان
    },
    
    routes: [
      GoRoute(path: '/login', builder: (_, __) => const LoginScreen()),
      GoRoute(path: '/home', builder: (_, __) => const HomePage()),
      // ... باقي الـ routes
    ],
  );
}
```

## 🔐 Route Guards (حماية الصفحات)

```dart
// مثال: حماية صفحة الموافقات
GoRoute(
  path: '/approvals',
  redirect: (context, state) {
    final authState = authCubit.state;
    
    if (authState is AuthAuthenticated) {
      final permissions = authState.user.permissions;
      
      // فحص الصلاحيات
      if (permissions.contains('all') ||         // Owner
          permissions.contains('approvals')) {   // Manager
        return null;  // ✅ السماح
      }
    }
    
    return '/home';  // ❌ رفض الوصول
  },
  builder: (_, __) => const ApprovalsPage(),
)

      // Owner فقط
      if (permissions.contains('all')) {
        return null;  // ✅ السماح
      }
    }
    
    return '/home';  // ❌ رفض الوصول
  },
  builder: (_, __) => const AdminDashboardPage(),
```
