## 🔄 Data Flow - متكامل ومترابط

### Flow 1: Authentication
```
LoginScreen
  ↓ User inputs credentials
AuthCubit.login()
  ↓
MockAuthApi.login()
  ↓ Check credentials
Memory Database (_users Map)
  ↓ Generate session & tokens
emit(AuthAuthenticated)
  ↓
GoRouter → redirect to /home
```

### Flow 2: Branches List
```
BranchesSimplePage
  ↓ BlocProvider creates BranchesCubit
BranchesCubit.loadBranches()
  ↓
MockBranchesApi.getBranches()
MockBranchesApi.getTodayStatistics()
  ↓
Memory Database (_branches List)
  ↓
emit(BranchesLoaded)
  ↓
UI rebuilds with data
  → _buildBranchCard() for each branch
```

### Flow 3: Branch Details
```
Tap on Branch Card
  ↓
context.push('/branch-details/${branchId}')
  ↓ GoRouter + Permission Guard
BranchDetailsPage._loadBranchDetails()
  ↓ 3 Parallel API Calls
├─ MockBranchesApi.getBranchDetails()
├─ MockBranchesApi.getBranchEmployees()
└─ MockBranchesApi.getBranchStatistics()
  ↓
setState with all data
  ↓
UI renders:
├─ _buildInfoCard()
├─ _buildManagerCard()
├─ _buildEmployeesCard()
├─ _buildInstallmentsCard() ← Clickable
└─ _buildReportsCard()
```

### Flow 4: Branch Installments
```
Tap on "الأقساط" in Branch Details
  ↓
context.push('/branch-installments/${branchId}')
  ↓
BranchInstallmentsPage._loadInstallments()
  ↓
MockInstallmentsApi.getCustomersWithContracts()
  ↓ Extract all contracts
Filter by branchId
  ↓ Split into 5 categories
_allInstallments
_activeInstallments
_overdueInstallments
_completedInstallments
_cancelledInstallments
  ↓
TabBarView displays 5 tabs
  → _buildInstallmentsList() for each tab
```

### Flow 5: Create Installment Request
```
Tap FAB "قسط جديد" in Installments Page
  ↓
context.go('/create-installment-request')
  ↓ GoRouter + Permission Guard
CreateInstallmentRequestPage
  ↓ User fills form
Submit button
  ↓
MockInstallmentRequestsApi.createRequest()
  ↓ Add to _requests List
MockNotificationsApi.notifyRequestCreated()
  ↓ Notify Owner
Navigate back to Approvals Page
  ↓
ApprovalsPage refreshes
  → New request appears in list
```

### Flow 6: Approve/Reject Request
```
Owner/Manager opens Request Details
  ↓
_canApproveOrReject() → true
  ↓ Both buttons visible
Tap "موافقة" or "رفض"
  ↓
Confirmation Dialog
  ↓ User confirms
MockInstallmentRequestsApi.approveRequest()
  or
MockInstallmentRequestsApi.rejectRequest()
  ↓ Update status in _requests
If approved:
  MockInstallmentsApi.createContractFromRequest()
    ↓ Create new contract in _contracts
MockNotificationsApi.notify*()
  ↓ Notify Manager
Navigate back
  ↓
ApprovalsPage refreshes
  → Updated status shows
```

- **المسؤولية:** جلب وحفظ البيانات فقط
- **لا تعرف:** أي شيء عن UI أو State Management
- **ترجع:** Pure Data (Maps, Lists, Models)

```dart
// ✅ مثال من MockBranchesApi
Future<Map<String, dynamic>> getBranchDetails(String branchId) async {
  await _client.get('/branches/$branchId');
  
  final branch = _branches.firstWhere(
    (b) => b['id'] == branchId,
    orElse: () => throw MockNetworkException('الفرع غير موجود'),
  );
  
  return {
    'success': true,
    'data': {
      ...branch,
      'email': '${branchId.toLowerCase()}@codit.gold',
      'manager_id': 'MGR-${branchId.split('-').last}',
    },
  };
}
```

### ✅ Presentation Layer (Cubit):
- **المسؤولية:** State Management فقط
- **لا تحتوي:** على UI Widgets
- **تستدعي:** Data Layer فقط

```dart
// ✅ مثال من BranchesCubit
class BranchesCubit extends Cubit<BranchesState> {
  final MockBranchesApi _api = MockBranchesApi();

  Future<void> loadBranches() async {
    try {
      emit(BranchesLoading());
      
      final branches = await _api.getBranches();
      final stats = await _api.getTodayStatistics();
      
      emit(BranchesLoaded(branches: branches, statistics: stats));
    } catch (e) {
      emit(BranchesError(message: e.toString(), onRetry: loadBranches));
    }
  }
}
```

### ✅ UI Layer:
- **المسؤولية:** عرض البيانات فقط
- **لا تحتوي:** على Business Logic
- **تستدعي:** Cubit methods فقط

```dart
// ✅ مثال من BranchesSimplePage
class _BranchesPageContent extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return BlocBuilder<BranchesCubit, BranchesState>(
      builder: (context, state) {
        if (state is BranchesLoading) {
          return const ShimmerBranchesList();
        } else if (state is BranchesLoaded) {
          return ListView.builder(
            itemCount: state.branches.length,
            itemBuilder: (ctx, index) {
              final branch = state.branches[index];
              return _buildBranchCard(ctx, branch);
            },
          );
        } else if (state is BranchesError) {
          return ErrorWidget(
            message: state.message,
            onRetry: state.onRetry,
          );
        }
        return const SizedBox.shrink();
      },
    );
  }
}
```
