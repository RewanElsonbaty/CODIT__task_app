# ⚡ دليل الاستخدام السريع - نظام معالجة الأخطاء

## 🎯 متى تستخدم كل نوع من الاستثناءات؟

### 1. **ServerException** 🖥️
**متى؟** عند حدوث خطأ من الخادم (500, 503, etc)
```dart
throw ServerException('خطأ في الخادم', code: 500);
```

### 2. **NetworkException** 🌐
**متى؟** عند فشل الاتصال بالإنترنت
```dart
throw NetworkException('لا يوجد اتصال بالإنترنت');
```

### 3. **MockNetworkException** 🔌
**متى؟** عند فشل Mock API (للتطوير)
```dart
throw MockNetworkException('فشل الاتصال بخدمة المصادقة');
```

### 4. **ValidationException** ✍️
**متى؟** عند فشل التحقق من البيانات
```dart
throw ValidationException('البريد الإلكتروني غير صحيح');
```

### 5. **ConflictException** ⚠️
**متى؟** عند وجود تعارض في البيانات
```dart
throw ConflictException('اسم المستخدم موجود بالفعل');
```

### 6. **VersionConflictException** 🔄
**متى؟** عند تعارض إصدار البيانات
```dart
throw VersionConflictException(
  message: 'تم تحديث البيانات من مستخدم آخر',
  latestVersion: 2,
);
```

### 7. **CacheException** 💾
**متى؟** عند فشل في قراءة/كتابة Cache
```dart
throw CacheException('فشل في حفظ البيانات محلياً');
```

### 8. **AuthException** 🔐
**متى؟** عند فشل المصادقة (خطأ في اسم مستخدم/كلمة مرور)
```dart
throw AuthException('اسم المستخدم أو كلمة المرور غير صحيحة');
```

### 9. **UnauthorizedException** 🚫
**متى؟** عند محاولة الوصول لصفحة بدون صلاحيات
```dart
throw UnauthorizedException('لا تملك صلاحية الوصول لهذه الصفحة');
```

### 10. **NotFoundException** 🔍
**متى؟** عند البحث عن شيء غير موجود
```dart
throw NotFoundException('المنتج غير موجود');
```

### 11. **TimeoutException** ⏱️
**متى؟** عند انتهاء وقت العملية
```dart
throw TimeoutException('انتهى وقت الاتصال بالخادم');
```

## 🎨 متى تستخدم كل نوع من الرسائل؟

### 1. **Success (أخضر 🟢)**
```dart
ExceptionHandler.showSuccessSnackBar(context, 'تم الحفظ بنجاح');
```
**أمثلة الاستخدام:**
- ✅ تم تسجيل الدخول بنجاح
- ✅ تم حفظ البيانات
- ✅ تم إرسال الطلب
- ✅ تمت الموافقة على الطلب

### 2. **Warning (برتقالي 🟠)**
```dart
ExceptionHandler.showWarningSnackBar(context, 'تحذير: بيانات غير مكتملة');
```
**أمثلة الاستخدام:**
- ⚠️ بيانات غير مكتملة
- ⚠️ يوجد حقول فارغة
- ⚠️ القيمة أقل من الحد الأدنى
- ⚠️ ستنتهي صلاحيتك قريباً

### 3. **Info (أزرق 🔵)**
```dart
ExceptionHandler.showInfoSnackBar(context, 'نصيحة: احفظ التغييرات بشكل دوري');
```
**أمثلة الاستخدام:**
- ℹ️ نصيحة أو ملاحظة
- ℹ️ معلومة إضافية
- ℹ️ تذكير
- ℹ️ إرشاد للمستخدم

### 4. **Error (أحمر 🔴)**
```dart
ExceptionHandler.showErrorSnackBar(context, e);
// أو
ExceptionHandler.showErrorDialog(context, e);
```
**أمثلة الاستخدام:**
- ❌ فشل في تسجيل الدخول
- ❌ خطأ في الاتصال
- ❌ فشل في حفظ البيانات
- ❌ خطأ غير متوقع

## 🛠️ أمثلة عملية

### مثال 1: تسجيل دخول مع معالجة شاملة
```dart
Future<void> _login() async {
  try {
    // محاولة تسجيل الدخول
    final user = await authApi.login(
      _usernameController.text,
      _passwordController.text,
    );
    
    // نجح
    ExceptionHandler.showSuccessSnackBar(
      context,
      'مرحباً ${user.name}',
    );
    
    // الانتقال للصفحة الرئيسية
    context.go('/home');
    
  } on AuthException catch (e) {
    // خطأ في اسم المستخدم/كلمة المرور
    ExceptionHandler.showErrorDialog(context, e);
    
  } on UnauthorizedException catch (e) {
    // الحساب غير نشط
    ExceptionHandler.showErrorDialog(context, e);
    
  } on NetworkException catch (e) {
    // لا يوجد إنترنت
    ExceptionHandler.showErrorSnackBar(context, e);
    
  } catch (e, stackTrace) {
    // خطأ غير متوقع
    ExceptionHandler.logException(e, stackTrace);
    ExceptionHandler.showErrorSnackBar(
      context,
      'حدث خطأ غير متوقع، حاول مرة أخرى',
    );
  }
}
```

### مثال 2: تحميل منتجات مع handleException
```dart
Future<void> _loadProducts() async {
  setState(() => _isLoading = true);
  
  final products = await ExceptionHandler.handleException<List<Product>>(
    operation: () => goldApi.getAllProducts(),
    context: context,
    showSnackBar: true,
    errorMessage: 'فشل في تحميل المنتجات',
    defaultValue: [],
  );
  
  setState(() {
    _products = products;
    _isLoading = false;
  });
  
  if (products.isNotEmpty) {
    ExceptionHandler.showSuccessSnackBar(
      context,
      'تم تحميل ${products.length} منتج',
    );
  }
}
```

### مثال 3: حفظ بيانات مع تحقق
```dart
Future<void> _saveData() async {
  // تحقق من البيانات
  if (_nameController.text.isEmpty) {
    ExceptionHandler.showWarningSnackBar(
      context,
      'الرجاء إدخال الاسم',
    );
    return;
  }
  
  if (_priceController.text.isEmpty) {
    ExceptionHandler.showWarningSnackBar(
      context,
      'الرجاء إدخال السعر',
    );
    return;
  }
  
  try {
    // حفظ البيانات
    await goldApi.createProduct(
      name: _nameController.text,
      price: double.parse(_priceController.text),
    );
    
    // نجح
    ExceptionHandler.showSuccessSnackBar(
      context,
      'تم حفظ المنتج بنجاح',
    );
    
    // رجوع للصفحة السابقة
    Navigator.pop(context);
    
  } on ValidationException catch (e) {
    ExceptionHandler.showErrorSnackBar(context, e);
    
  } on ConflictException catch (e) {
    ExceptionHandler.showErrorDialog(context, e);
    
  } catch (e, stackTrace) {
    ExceptionHandler.logException(e, stackTrace);
    ExceptionHandler.showErrorSnackBar(
      context,
      'فشل في حفظ البيانات',
    );
  }
}
```

### مثال 4: بحث عن منتج
```dart
Future<void> _searchProduct(String id) async {
  try {
    final product = await goldApi.getProductById(id);
    
    // وجد المنتج
    ExceptionHandler.showInfoSnackBar(
      context,
      'تم العثور على: ${product.name}',
    );
    
    // عرض تفاصيل المنتج
    _showProductDetails(product);
    
  } on NotFoundException catch (e) {
    // المنتج غير موجود
    ExceptionHandler.showWarningSnackBar(context, e);
    
  } on TimeoutException catch (e) {
    // انتهى وقت البحث
    ExceptionHandler.showErrorSnackBar(context, e);
    
  } catch (e) {
    ExceptionHandler.logException(e);
    ExceptionHandler.showErrorSnackBar(
      context,
      'فشل في البحث',
    );
  }
}
```

### مثال 5: عملية مع تقدم
```dart
Future<void> _processWithProgress() async {
  // عرض معلومة
  ExceptionHandler.showInfoSnackBar(
    context,
    'جاري معالجة البيانات...',
  );
  
  try {
    final result = await goldApi.processData();
    
    // نجحت العملية
    ExceptionHandler.showSuccessSnackBar(
      context,
      'تمت المعالجة بنجاح',
    );
    
  } on TimeoutException catch (e) {
    // العملية أخذت وقت طويل
    ExceptionHandler.showWarningSnackBar(
      context,
      'العملية تأخذ وقت أطول من المعتاد، حاول مرة أخرى',
    );
    
  } catch (e) {
    ExceptionHandler.showErrorSnackBar(context, e);
  }
}
```

## 🎓 نصائح مهمة

### 1. استخدم showErrorDialog للأخطاء المهمة:
```dart
// خطأ مهم يحتاج انتباه المستخدم
ExceptionHandler.showErrorDialog(context, 'الحساب غير نشط');
```

### 2. استخدم showErrorSnackBar للأخطاء البسيطة:
```dart
// خطأ بسيط يمكن تجاهله
ExceptionHandler.showErrorSnackBar(context, 'فشل في تحميل الصورة');
```

### 3. دائماً سجل الأخطاء في Development:
```dart
catch (e, stackTrace) {
  ExceptionHandler.logException(e, stackTrace);
  // ...
}
```

### 4. استخدم handleException للعمليات المتكررة:
```dart
// بدلاً من كتابة try-catch في كل مكان
final result = await ExceptionHandler.handleException(
  operation: () => api.getData(),
  context: context,
  showSnackBar: true,
  defaultValue: [],
);
```

### 5. كن واضحاً في الرسائل:
```dart
// ❌ سيء
throw ValidationException('خطأ');

// ✅ جيد
throw ValidationException('البريد الإلكتروني غير صحيح');

// ✅ أفضل
throw ValidationException('البريد الإلكتروني يجب أن يحتوي على @');
```

## 🔥 أمثلة سيناريوهات حقيقية

### سيناريو 1: إضافة منتج جديد
```dart
Future<void> _addProduct() async {
  // 1. تحقق من الصلاحيات
  if (!_hasPermission('create_product')) {
    ExceptionHandler.showErrorDialog(
      context,
      UnauthorizedException('لا تملك صلاحية إضافة منتجات'),
    );
    return;
  }
  
  // 2. تحقق من البيانات
  if (_form.validate()) {
    try {
      // 3. أظهر معلومة
      ExceptionHandler.showInfoSnackBar(
        context,
        'جاري حفظ المنتج...',
      );
      
      // 4. احفظ المنتج
      final product = await goldApi.createProduct(...);
      
      // 5. نجح
      ExceptionHandler.showSuccessSnackBar(
        context,
        'تم إضافة ${product.name} بنجاح',
      );
      
      Navigator.pop(context, product);
      
    } on ValidationException catch (e) {
      ExceptionHandler.showWarningSnackBar(context, e);
    } on ConflictException catch (e) {
      ExceptionHandler.showErrorDialog(context, e);
    } catch (e) {
      ExceptionHandler.logException(e);
      ExceptionHandler.showErrorSnackBar(
        context,
        'فشل في حفظ المنتج',
      );
    }
  }
}
```
