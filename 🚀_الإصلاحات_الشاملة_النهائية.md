## ✅ الإصلاحات المنفذة

### 1. ✅ إصلاح Null Safety في MockAuthApi

**المشكلة:**
```
Error: The argument type 'Null' can't be assigned to the parameter type 'String'.
branchId: null,  // ← Error في 3 مواضع
```

**السبب:**
- `branchId` كان معرف كـ `String` (non-nullable)
- المالك ومدير الأقساط لا ينتميان لفرع محدد
- يحتاجون `branchId: null`

**الحل:**
```dart
// ❌ قبل
class MockUser {
  final String branchId;  // ← non-nullable
  
  MockUser({
    required this.branchId,  // ← required
    // ...
  });
}

// ✅ بعد
class MockUser {
  final String? branchId;  // ← nullable
  
  MockUser({
    this.branchId,  // ← optional
    // ...
  });
}
```

**النتيجة:**
```dart
// ✅ الآن يعمل بدون أخطاء
'owner': MockUser(
  id: 'OWNER-001',
  branchId: null,  // ← OK
  // ...
),

'installments_manager': MockUser(
  id: 'INST-MGR-001',
  branchId: null,  // ← OK
  // ...
),
```
