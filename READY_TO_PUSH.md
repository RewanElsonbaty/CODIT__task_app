## 📞 في حالة وجود مشكلة

### المشاكل الشائعة:

**1. "Repository not found"**
- تأكد إنك أنشأت الـ repo على GitHub أولاً

**2. "Authentication failed"**
- استخدم Personal Access Token بدل Password
- Or use GitHub Desktop

**3. "Permission denied"**
- تأكد إنك مسجل دخول على GitHub
- تأكد إن عندك صلاحيات على الحساب

**4. "Remote origin already exists"**
```bash
git remote remove origin
git remote add origin https://github.com/rawanelsenbaty/CODIT-TASK.git
```
