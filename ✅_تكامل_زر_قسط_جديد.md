# ✅ تكامل زر "قسط جديد" مع نظام الموافقات
# Integration of "New Installment" Button with Approvals System

---

## 🎯 ما تم تنفيذه

تم ربط زر **"قسط جديد"** في صفحة الأقساط مع نظام الموافقات بشكل كامل.

---

## 🔧 التغييرات

### Before (❌):
```dart
floatingActionButton: FloatingActionButton.extended(
  onPressed: () {
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('إضافة قسط جديد')),
    );
  },
  // ... زر غير فعّال
)
```

### After (✅):
```dart
floatingActionButton: FloatingActionButton.extended(
  onPressed: () {
    // الانتقال لصفحة إنشاء طلب قسط جديد
    context.go('/create-installment-request');
  },
  backgroundColor: AppColors.primary,
  icon: const Icon(Icons.add),
  label: const Text('قسط جديد'),
)
```

## 🔄 التدفق الكامل

### 1. المستخدم في صفحة الأقساط
```
📱 Installments Page
  ├── عرض جميع الأقساط
  ├── إحصائيات
  └── زر "قسط جديد" ✨
```

### 2. الضغط على "قسط جديد"
```
👆 User clicks "قسط جديد"
  ↓
🚀 Navigation to: /create-installment-request
  ↓
📄 Create Installment Request Page
```

### 3. صفحة إنشاء طلب القسط
```
📝 Create Installment Request Form
  ├── اسم العميل
  ├── رقم الهاتف
  ├── الرقم القومي (14 رقم)
  ├── رقم الفاتورة
  ├── رقم العميل
  ├── المبلغ الإجمالي
  ├── القسط الشهري
  ├── عدد الأقساط
  ├── معاد الدفع
  ├── الفرع
  └── ملاحظات
```

### 4. إرسال الطلب
```
✅ Submit Request
  ↓
💾 Save to Mock API
  ↓
📨 Notification to Owner
  ↓
🔄 Navigate to: /installment-requests
```

## 📝 الاستخدام

### للمدير (Manager):
```
1. افتح صفحة "الأقساط"
2. اضغط على زر "قسط جديد" (FAB)
3. املأ نموذج طلب القسط
4. أرسل الطلب
5. انتظر موافقة المالك
```

### للمالك (Owner):
```
1. استلم إشعار بطلب جديد
2. افتح صفحة "طلبات التقسيط"
3. راجع الطلب
4. وافق أو ارفض
5. (إذا وافقت) → يُنشأ عقد القسط تلقائياً
```
