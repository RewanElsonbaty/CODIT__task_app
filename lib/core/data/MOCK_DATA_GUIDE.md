```

c/C/س  → سلاسل
b/B/ا  → أساور
```

## 📝 مثال على الاستخدام

### إضافة منتج جديد:
```dart
_products.add(
  GoldProduct(
    code: 'RING-010',
    barcode: '1234567890160',
    name: 'خاتم ذهب عيار 21 - جديد',
    karat: Karat.k21,
    grossWeightMg: 5000,      // 5 جرام
    stonesWeightMg: 300,      // 0.3 جرام فصوص
    status: ProductStatus.available,
    category: 'خواتم',
    makingChargePerGram: 55.0,
  ),
);
```

### حساب السعر:
```dart
// الوزن الصافي = الوزن القائم - وزن الفصوص
netWeight = (5000 - 300) / 1000 = 4.7 جرام

// سعر الذهب
goldPrice = 4.7 × 3200 = 15,040 جنيه

// المصنعية
makingCharge = 4.7 × 55 = 258.5 جنيه

// السعر الإجمالي
totalPrice = 15,040 + 258.5 = 15,298.5 جنيه
```

## 🔍 التحقق من المخزون

### الكود:
```dart
// Get available products
final availableProducts = _products
    .where((p) => p.status == ProductStatus.available)
    .toList();

// Get products by category
final rings = _products
    .where((p) => p.category == 'خواتم')
    .toList();

// Get products by karat
final karat21 = _products
    .where((p) => p.karat == Karat.k21)
    .toList();

// Get products by weight range
final lightProducts = _products
    .where((p) => p.netWeightGrams >= 2 && p.netWeightGrams <= 5)
    .toList();
```
