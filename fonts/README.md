# خطوط التطبيق - Cairo Font

## تحميل الخطوط

قم بتحميل خطوط Cairo من Google Fonts:
https://fonts.google.com/specimen/Cairo

## الملفات المطلوبة:

ضع الملفات التالية في هذا المجلد:

1. **Cairo-Regular.ttf** (وزن 400)
2. **Cairo-Medium.ttf** (وزن 500)
3. **Cairo-SemiBold.ttf** (وزن 600)
4. **Cairo-Bold.ttf** (وزن 700)
5. **Cairo-ExtraBold.ttf** (وزن 800)

## طريقة التحميل السريعة:

```bash
# من Google Fonts
https://fonts.google.com/download?family=Cairo

# أو استخدم هذا الأمر (يتطلب wget):
wget https://github.com/google/fonts/raw/main/ofl/cairo/Cairo-Regular.ttf
wget https://github.com/google/fonts/raw/main/ofl/cairo/Cairo-Medium.ttf
wget https://github.com/google/fonts/raw/main/ofl/cairo/Cairo-SemiBold.ttf
wget https://github.com/google/fonts/raw/main/ofl/cairo/Cairo-Bold.ttf
wget https://github.com/google/fonts/raw/main/ofl/cairo/Cairo-ExtraBold.ttf
```
