```dart
Future<Map<String, dynamic>> login({
  required String username,
  required String password,
  required String deviceId,
}) async {
  try {
    // التحقق من فراغ البيانات
    if (username.isEmpty || password.isEmpty) {
      throw ValidationException('الرجاء إدخال اسم المستخدم وكلمة المرور');
    }

    // التحقق من بيانات الاعتماد
    final user = _users[username];
    if (user == null) {
      throw NotFoundException('المستخدم غير موجود');
    }

    if (user.password != password) {
      throw AuthException('كلمة المرور غير صحيحة');
    }

    // ... إنشاء Session
    
  } on ValidationException {
    rethrow;
  } on NotFoundException {
    rethrow;
  } on AuthException {
    rethrow;
  } catch (e) {
    throw MockNetworkException('فشل الاتصال بخدمة المصادقة: ${e.toString()}');
  }
}
```

### 3. **Clean Architecture الصحيح** 🏗️

```
Feature/
├── data/                           ← Data Layer
│   ├── mock_xxx_api.dart          ← يرمي Exceptions
│   └── repository_impl.dart       ← يحوّل إلى Failures
│
├── domain/                         ← Domain Layer
│   ├── repository.dart            ← Interface (Either<Failure, Data>)
│   ├── models/                    ← Domain Models
│   └── usecases/ (optional)       ← Business Logic
│
└── presentation/                   ← Presentation Layer
    ├── cubit/                     ← State Management
    │   ├── xxx_cubit.dart         ← يستقبل Failures
    │   └── xxx_state.dart         ← States
    └── screens/                   ← UI
        └── xxx_screen.dart        ← يعرض رسائل للمستخدم
```

### 5. **Logic و Flow المتكامل** 🔄

#### مثال: Flow تسجيل الدخول الكامل

```
1. User Input (LoginScreen)
   ↓
2. Form Validation (UI Level)
   ↓ (if valid)
3. AuthCubit.login()
   ↓
4. AuthRepository.login()
   ↓
5. MockAuthApi.login()
   ├─ ValidationException → يتحقق من البيانات
   ├─ NotFoundException → يتحقق من وجود المستخدم
   ├─ AuthException → يتحقق من كلمة المرور
   └─ UnauthorizedException → يتحقق من حالة الحساب
   ↓ (if success)
6. Create Session + Tokens
   ↓
7. Save to SecureStorage
   ↓
8. AuthCubit → emit(AuthAuthenticated)
   ↓
9. GoRouter → redirect to /home
   ↓
10. HomePage → يعرض بيانات المستخدم
```

#### مثال: Flow إنشاء عقد تقسيط

```
1. CreateContractScreen (Form)
   ↓
2. Form Validation
   ↓
3. InstallmentsCubit.createContract()
   ↓
4. InstallmentsRepository.createContract()
   ↓
5. MockInstallmentsApi.createContract()
   ├─ ValidationException → تحقق من البيانات
   ├─ NotFoundException → تحقق من العميل
   ├─ UnauthorizedException → تحقق من Credit Score
   └─ ConflictException → تحقق من الديون المتأخرة
   ↓ (if success)
6. Create Contract في Database
   ↓
7. Update Customer Data
   ↓
8. InstallmentsCubit → emit(ContractCreated)
   ↓
9. UI → ExceptionHandler.showSuccessSnackBar()
   ↓
10. Navigate back مع Contract
```

### 3. UI Feedback الصحيح:
```dart
// ❌ خطأ - بدون رسائل
await repository.createData();
Navigator.pop(context);

// ✅ صحيح - مع رسائل واضحة
final result = await repository.createData();
result.fold(
  (failure) => ExceptionHandler.showErrorSnackBar(context, failure.message),
  (data) {
    ExceptionHandler.showSuccessSnackBar(context, 'تم الحفظ بنجاح');
    Navigator.pop(context, data);
  },
);
```
