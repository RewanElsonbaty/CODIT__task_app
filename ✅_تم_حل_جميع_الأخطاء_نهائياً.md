## 🎓 Clean Architecture Principles

### 1. Separation of Concerns ✅
```dart
// Service Layer - Business Logic
class NotificationSchedulerService {
  // Pure business logic
  // No UI dependencies
}

// Config Layer - Infrastructure
class NotificationSchedulerConfig {
  // Timer management
  // System integration
}
```

### 2. Dependency Inversion ✅
```dart
// Depends on abstractions (interfaces)
// Not on concrete implementations
NotificationSchedulerService({
  MockInstallmentsApi? installmentsApi,  // Can inject any implementation
  MockNotificationsApi? notificationsApi, // Can inject any implementation
});
```

### 3. Single Responsibility ✅
```dart
// Each method has ONE responsibility
Future<void> checkDuePaymentsToday() async {
  // Only checks due payments
}

Future<void> checkOverduePayments() async {
  // Only checks overdue payments
}
```
