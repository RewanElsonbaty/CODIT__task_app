### 2. ✅ branches_simple_page.dart - context غير معرّف

**المشكلة:**
- الدالة `_buildBranchCard()` لا تأخذ `BuildContext`
- استخدام `context.push()` بدون تمريره كمعامل

**الحل:**
```dart
// ❌ قبل
Widget _buildBranchCard(Map<String, dynamic> branch) {
  return InkWell(
    onTap: () {
      context.push('/branch-details/${branch['id']}');  // ← خطأ: context غير معرف
    },
    // ...
  );
}

// ✅ بعد
Widget _buildBranchCard(BuildContext context, Map<String, dynamic> branch) {
  return InkWell(
    onTap: () {
      context.push('/branch-details/${branch['id']}');  // ✅ صح
    },
    // ...
  );
}

// تحديث الاستدعاء
itemBuilder: (context, index) {
  final branch = state.branches[index];
  return _buildBranchCard(context, branch);  // ✅ تمرير context
},
```

## 🔄 الـ Flow المظبوط

### Flow 1: تحميل الفروع

```dart
// 1. User opens branches page
BranchesSimplePage → BlocProvider → BranchesCubit()

// 2. Cubit auto-loads on init
BranchesCubit() → loadBranches()

// 3. API call
loadBranches() → MockBranchesApi.getBranches()

// 4. Update UI
emit(BranchesLoaded(branches, stats))

// 5. UI rebuilds with data
BlocBuilder<BranchesCubit, BranchesState>
  → _buildBranchCard(context, branch)
```

### Flow 2: الانتقال لتفاصيل الفرع

```dart
// 1. User taps branch card
InkWell.onTap()

// 2. Navigation with context
context.push('/branch-details/${branch['id']}')

// 3. BranchDetailsPage loads
_loadBranchDetails()
  → MockBranchesApi.getBranchDetails()
  → MockBranchesApi.getBranchEmployees()
  → MockBranchesApi.getBranchStatistics()

// 4. UI displays data
_buildInfoCard()
_buildEmployeesCard()
_buildInstallmentsCard()
```

### Flow 3: الانتقال لأقساط الفرع

```dart
// 1. User taps "الأقساط" in branch details
InkWell.onTap()

// 2. Navigation
context.push('/branch-installments/${branchId}')

// 3. BranchInstallmentsPage loads
_loadInstallments()
  → MockInstallmentsApi.getCustomersWithContracts()
  → Filter by branchId
  → Split into 5 tabs

// 4. UI displays tabs
TabBarView(
  _allInstallments,
  _activeInstallments,
  _overdueInstallments,
  _completedInstallments,
  _cancelledInstallments,
)
```
